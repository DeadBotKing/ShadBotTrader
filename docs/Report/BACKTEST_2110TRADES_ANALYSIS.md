### نمونهٔ قطعی (ترید #۱۴)

```
direction      : LONG
entry_price    : 4482.34
stop_loss      : 4533.68   ← +$51 بالاتر از entry!
take_profit    : 4594.28   ← +$112 بالاتر
predicted_low  : 4536.37   ← رنج: 4536–4594 حول reference=4563
exit_reason    : stop_loss (در SL!)
net_pnl        : +0.50  (چون قیمت به SL=«بالا» رسیده = سود)
```

### ریشهٔ دقیق

مدل رنج high/low **فردا** را حول close دیروز پیش‌بینی می‌کند (اینجا 4536–4594 حول 4563).
اما سیگنال ممکن است فردا وقتی بیاید که قیمت به 4482 (۱.۲٪ پایین‌تر) حرکت کرده باشد.
براکت از سطوح خام رنج ساخته می‌شود:

- LONG: TP = predicted_high = 4594 (بالا از entry ✓)
- LONG: SL = predicted_low − spread = 4533 (**بالا از entry ✗**)

سپس `from_model_levels` با `reward_risk_multiplier` بررسی R/R می‌کند ولی
**با فاصلهٔ مطلق** (`abs(TP−entry)` و `abs(entry−SL)`) — پس وقتی entry بیرون
رنج است هر دو فاصله مثبت‌اند و R/R ریاضی «OK» به نظر می‌رسد → براکت تایید می‌شود.

### چرا این تریدها «می‌برند»؟

براکت وارونه یعنی «SL» در واقع **هدف سود** است و «TP» مرز دورِ ضرر.
چون SL (هدف واقعی) نزدیک‌تر از TP است، قیمت در همان کندل ورود به آن
می‌خورد → **۸۹.۱٪ تریدها 0-candle** هستند (باز و بسته در همان کندل) →
هر بار PnL کوچک مثبت → ۲,۱۱۰ بار تکرار → +۴۷۳٪ مرکب.

### اثبات PnL محاسباتی درست است

`net_pnl` هر ۲,۱۱۰ ترید با `(exit − entry) × direction × qty` سازگار است
(صفر ناسازگاری). یعنی **حسابداری درست است؛ منطقِ ورود/براکت خراب است.**

## ۴. چیزهایی که سالم کار کردند ✅

- **حداکثر ۱ پوزیشن همزمان** — صفر هم‌پوشانی (idempotency تصمیم‌ها کار می‌کند)
- **accounting**: PnL هر ۲,۱۱۰ ترید سازگار با (exit−entry)×qty
- **spread cost** واقعی حساب شده (۵۳.۵۵)
- **رنج فقط برای actionable ها**: ۸۱۱ سیگنال actionable → رنج برای همه اجرا شد
  بعد از فیکس باگ ۵۱ (قبلاً ۰ بود)
- **نبود lookahead در fill**: exit روی bid با اسپرد (LONG: exit = SL − spread/2)

## ۵. 🛠️ فیکس‌های لازم (باگ ۵۲)

1. **Gate براکت سالم (بحرانی):** در `from_model_levels` — اگر برای LONG
   `SL ≥ entry_reference` یا برای SHORT `SL ≤ entry_reference` بود →
   `ValidationError` (براکت رد). همین یک شرط، ۱,۷۱۹ ترید معیوب را حذف می‌کند.
2. **Gate فاصلهٔ رنج (پیشنهادی):** اگر `|entry − reference_close| / reference > X٪`
   (مثلاً ۰.۵٪) → رنج کهنه است، ترید رد.
3. **گزارش exit-price صادقانه:** `exit_reason=stop_loss` برای تریدی که سود
   کرده گمراه‌کننده است — شاید `exit_side=target_side` بهتر باشد.
4. (اختیاری) max ترید در روز/ساعت برای جلوگیری از over-trading.

**بعد از فیکس ۱:** فقط ۳۹۱ تریدِ «براکت سالم» باقی می‌مانند که PnL واقعی
آن‌ها **−۷.۹۱** است — یعنی وضعیت واقعی سیستم فعلی: **اندکی ضررده**.
این عدد واقعی است که باید بهبود یابد (آستانه، session filter، آموزش بهتر).
