## ۳. خروجی واقعی — هر سه مسیر

```
tick 1/3  [no_trade] signal model says hold (65.0%)
  signal : sell 20.0% | hold 65.0% | buy 15.0% -> hold 65.0%
  range  : high 2046.85 | low 2020.50 | r/r 3.33

tick 2/3  [no_trade] reward/risk 0.30 < 1.20
  signal : sell 85.0% | hold 10.0% | buy 5.0% -> sell 85.0%

tick 3/3  [traded] signal buy 90.0%, target 2046.85, r/r 3.33
  signal : sell 5.0% | hold 5.0% | buy 90.0% -> buy 90.0%
  filled : 0.01 @ 2028.58
```

دقیقاً همان چیزی که در پیامت توصیف کردی: سیگنال + قیمت‌های آینده → تصمیم.

## ۴. استراتژی دومدلی — شش دروازه

مدل سیگنال **جهت** را پیشنهاد می‌دهد؛ مدل رنج می‌گوید **ارزشش را دارد یا نه**.
یک خرید با اطمینان ۹۰٪ که ۲ دلار سود و ۲۰ دلار ضرر پیش‌بینی‌شده دارد،
معاملهٔ بدی است — و فقط مدل دوم می‌تواند این را بگوید.

| # | دروازه | رد شود → |
|---|---|---|
| ۱ | هر دو forecast موجود | HOLD |
| ۲ | مدل HOLD نگفته باشد | HOLD |
| ۳ | اطمینان ≥ حد آستانه | HOLD |
| ۴ | رنج منسجم (سقف بالای کف) | HOLD |
| ۵ | reward/risk ≥ حداقل | HOLD |
| ۶ | حرکت > کف هزینه | HOLD |

**هر رد شدن دلیلش را می‌گوید.** یک رد بی‌صدا به‌اندازهٔ یک معاملهٔ غلط بد است —
هیچ‌کدام ساعت ۳ صبح قابل تشخیص نیست.

## ۵. 🐞 ناسازگاری گزارش reward/risk

برای **فروش**، reward و risk جا عوض می‌کنند. `RangeForecast.reward_risk()`
دید long-oriented است، پس چاپ مستقیمش با دروازه‌ای که تازه معامله را تأیید
کرده **تناقض** داشت:

```
قبل:  SELL -> ... r/r 0.25     ← ولی دروازه ۴.۰ حساب کرده بود
بعد:  SELL -> ... r/r 4.00     ← سازگار
```

**mypy هم یک سایه‌افتادن متغیر گرفت**: نام `forecast` برای دو نوع مختلف در یک
scope استفاده شده بود.

## ۶. بک‌تست با مدل — علیت مهم‌ترین چیز است

`ModelPredictionSource` پورت موجود را پیاده می‌کند، پس موتور **دست‌نخورده**
ماند و همچنان کندل ۰ تا آخر را یکی‌یکی طی می‌کند.

منبعی که به مدل اجازه دهد هنگام تصمیم در بار `t` بار `t+1` را ببیند، یک منحنی
سرمایهٔ زیبا تولید می‌کند و در واقعیت ضرر می‌دهد. دو تضمین:

- منبع پنجرهٔ **خودش** را نگه می‌دارد و فقط باری را اضافه می‌کند که موتور
  تحویل داده — چیز دیگری در دسترس نیست
- تا پر شدن پنجره `None` برمی‌گرداند (**خودداری**)، نه padding.
  پنجرهٔ padding شده یعنی مدل تاریخ جعلی می‌خواند

**سه کلاس روی یک محور:** پورت یک `float` می‌خواهد. از **directional
confidence** استفاده می‌شود — خرید نسبت به فروش، با نادیده‌گرفتن hold — پس
۰.۴۵/۰.۱۰/۰.۴۵ برابر ۰.۵ خوانده می‌شود (بلاتکلیف)، نه خرید ضعیف.

```
MODEL-DRIVEN BACKTEST (مدل واقعاً آموزش‌دیده)
  bars 700 | model calls 59 | trades 7 | return +12.35%
```

> ⚠️ **این عدد را جدی نگیر.** روی یک **موج سینوسی** است که ذاتاً قابل
> پیش‌بینی است. فقط ثابت می‌کند زنجیره کامل کار می‌کند، نه اینکه مدل خوب است.
> قضاوت واقعی نیازمند دیتای واقعی MT5 است.

## ۷. tick هرگز crash نمی‌کند

حلقهٔ بدون نظارت که با یک اختلال بروکر بمیرد، یعنی قطعی سرویس.

```python
status: "traded" | "no_trade" | "skipped" | "failed"
reason: همیشه پر
```

تستی هست که یک مدل عمداً خراب می‌دهد و ثابت می‌کند حلقه زنده می‌ماند و
tick بعدی دوباره کار می‌کند.
