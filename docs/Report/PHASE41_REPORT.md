## علت: ۱۲.۲ گیگابایت

```
49,393 windows × 500 rows × 123 cols × 4 bytes = 12.2 GB
ماتریس تخت اصلی                                 =   25 MB
```

`build_multi_target_samples` **همهٔ** پنجره‌ها را در ابتدای `train()`
می‌ساخت — قبل از اولین batch، و قبل از اولین خط لاگ. ماشین در همان
فاصله می‌مرد.

این توضیح می‌دهد چرا هر سه علامت با هم رخ می‌دادند:

| علامت | علت |
|---|---|
| رم پر می‌شد | ۱۲.۲ GB تخصیص |
| `waiting for the first line` | مرگ قبل از اولین `print` |
| مدلی ذخیره نشد | `save_model()` هرگز اجرا نشد |

اثبات با OOM killer در سندباکس:
```
Out of memory: Killed process (python) anon-rss:1284384kB
EXIT=137
```

**نکتهٔ تلخ:** فاز ۳۰ یک `WindowGenerator` تنبل ساخت دقیقاً برای همین
مشکل، با تست و مستندات — و هیچ‌وقت به trainer وصل نشد.

---

## رفع

فولدهای بزرگ حالا از همان ماتریس ۲۵ مگابایتی **استریم** می‌شوند:

```
STREAM_THRESHOLD_BYTES = 512 MB
```

زیر آستانه: مسیر ساده و سریع در حافظه. بالای آن: `tf.data` که هر batch
را در لحظه می‌سازد.

وقتی استریم فعال است، لیست نمونه‌ها **اصلاً ساخته نمی‌شود**؛ جایش
`_LazySampleCount` می‌نشیند که فقط تعداد را حساب می‌کند و اگر کسی
بخواهد ایندکسش کند خطا می‌دهد — یعنی مسیری که هنوز استریم را یاد
نگرفته، ساکت نمی‌ماند.

### اندازه‌گیری واقعی

```
series 20,000 × 125
materialising would need 4.8 GB
PEAK RSS: 966 MB          ← دو epoch، بدون OOM
VERDICT: STREAMED OK
```

**۴.۸ GB → ۹۶۶ MB.**

### یک باگ فرعی

`from_generator` بعد از یک pass تمام می‌شود، پس epoch دوم خالی بود و
Keras هشدار `ran out of data` می‌داد. با `repeat()` + `steps_per_epoch`
رفع شد.

---

## گزارش هزینه قبل از شروع

```
  windows        : 429 of 64 x 123
  if materialised: 0.0 GB  (streamed instead when large)
```

و اگر پنجره از دیتا بزرگ‌تر باشد، **فوراً** رد می‌کند نه بعد از ۸ دقیقه:

```
  [X] Not enough data: 497 rows cannot make a single 500-row window.
      Use a smaller --window, or fetch more candles.
```

این احتمالاً همان چیزی است که تو دیدی: `window=500` روی دیتاست ۱ روزه
(۲٬۱۵۲ سطر) شاید کار کند، ولی روی 5M با ۵۰k کندل ۱۲ GB می‌خواست.

## بدهی صریح

- **استریم کندتر از حافظه است** وقتی هر دو جا می‌شوند. آستانه ۵۱۲ MB
  محافظه‌کارانه انتخاب شد؛ تنظیم دقیقش نیاز به اندازه‌گیری روی سخت‌افزار
  تو دارد.

  حل کرد نه مسئلهٔ زمان را. batch بزرگ‌تر یا فولد کمتر لازم است.
