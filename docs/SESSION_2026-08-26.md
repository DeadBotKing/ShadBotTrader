### پروژه چیست

**ShadBotTrader** یک «پلتفرم معاملاتی AI سازمانی» است (Python / Clean
Architecture + DDD + Dependency Inversion + Event-Driven). هدف: یک رانتایم
قابل اجرا که در **SIMULATION** (پیشفرض)، **PAPER** و بعداً **LIVE** کار کند،
با بکتست قطعی، ریسک اجباری، و جداسازی سخت لایهها
(Domain مستقل از Infrastructure).

> ⚠️ نکتهٔ مهم: `docs/README.md` و `docs/CURRENT_STATE.md` و `docs/PROJECT_STATE.md`
> اسناد **طراحیِ منجمد** (فریز فاز ۲۶) هستند و عمداً «هنوز چیزی ساخته نشده»
> میگویند. این **کهنه** است. حقیقت در `IMPLEMENTATION_STATUS.md` + `WORKLOG.md`
> + گزارشهای فاز است. طبق `AGENTOPERATINGRULE`: **کد = واقعیت**، سند = نیت طراحی.

### نقشهٔ معماری (از مستندات)

```text
Interfaces (CLI / Dashboard)
      ↓
Application (Commands / Services / Workflows / Ports)
      ↓
Domain (Market / Trading / Risk / Portfolio / Strategy / ...)
      ↑
Infrastructure (Data / Execution / Persistence / Config / Logging)
```

**اجزای اصلی پیادهشده در `src/ShadBotTrader/`:**

| لایه | محتوا |
|---|---|
| `core/` | DI container، event bus، lifecycle، plugins (registry/manager)، services، result، errors |
| `domain/` | market، trading، portfolio، risk، strategy، dataset، feature، ai، execution، simulation، learning، deployment، account |
| `application/` | bootstrap، runtime، ~۱۶ سرویس (data، feature، training، dual_model، live_decision، backtest، ...) |
| `infrastructure/` | data (parquet/MT5)، feature (۲۰ calculator / ۱۰۹ فیچر)، ai (WaveNet)، trading، simulation، persistence (SQLite)، logging، config |
| `presentation/` | داشبورد وب + Command bus + ریپلی + Gateway |
| `project/` | Project Intelligence (scanner/builder/exporter) |

### کار اخیر (فازهای ۵۰–۵۶) — تمرکز فعلی پروژه

مدار آخرین کارها حول **بهینهسازی مدلهای دوگانه برای سوددهی بکتست طلا (XAUUSD)**
بوده:

| فاز | کار |
|---|---|
| ۵۰ | تحلیل range model (val_mae→دلار)، رفع باگ `loss_function` در save |
| ۵۱ | `--resume` — ادامهٔ آموزش از checkpoint بعد از disconnect کولب |
| ۵۲ | **فیلتر Session (ساعتهای خوب UTC) + حداقل فاصلهٔ SL** — Win Rate از ۳۳.۵٪ به ~۵۵٪ |
| ۵۳ | بهبود progress reporter (نمایش val_mae و معادل دلاری) |
| ۵۴ | Loss سهگانه (Huber+MAE+MSE) + AdamW + ReduceLROnPlateau (از legacy) |
| ۵۵ | **مدل رنج Seq2Seq** (خروجی `[batch, window, horizon*2]`) برای رفع collapse |
| ۵۶ | **Range: horizon=1 روی 1D** (پیشبینی high/low فردا) + سیگنال 5M |

**زنجیرهٔ ترید فعلی (بک‌تست دومدلی):**
`5M window → سیگنال BUY/SELL + confidence → گیت اطمینان → 1H/1D range →
high/low پیشبینی → براکت TP/SL → ورود next-open → خروج کندلبهکندل (stop-first) → PnL`

**گیتهای استراتژی (`dual_model_strategy.py`):** session filter · موجود بودن هر دو
forecast · اطمینان · انسجام range · R/R و هزینه · SL مینیمم.
