**تاریخ:** 2026-08-18
**وضعیت:** ✅ کامل — Quality Gate سبز

## ۱. آستانه، به درصد، در هر دو دکمه

```
Signal threshold %  [ 0.08 ]
```

فرم به **درصد** حرف می‌زند چون تریدر این‌طور فکر می‌کند؛ کد با **کسر**
حساب می‌کند چون بازده این‌طور محاسبه می‌شود. تبدیل یک‌جا انجام می‌شود:

| تایپ می‌کنی | به اسکریپت می‌رسد |
|---|---|
| `0.08` | `0.0008` |
| `0.15` | `0.0015` |
| `0.25%` | `0.0025` |
| خالی / غلط / منفی | `0.0008` (پیش‌فرض) |

یک تایپ اشتباه در فرم نباید یک اجرای درست را قطع کند، پس به‌جای خطا به
پیش‌فرض برمی‌گردد.

خروجی آموزش حالا **قاعدهٔ لیبل‌گذاری را صریح می‌گوید**:

```
label rule: a move of more than 0.1500% over 5 candles is BUY/SELL, otherwise HOLD
label balance  : {'sell': 40, 'hold': 626, 'buy': 29}
```

## ۲. اسپرد از خود متاتریدر — و باگی که پیدا شد

### باگ ۳۹ — اسپرد ۴ دلاری hard-code شده

در `live_decision_service.py` این بود:

```python
spread=Decimal("4"),
```

روی طلای ۴٬۳۷۶ دلاری این یعنی **۰.۰۹۱٪** هزینهٔ رفت‌وبرگشت. ولی آستانهٔ
پیش‌فرض مدل سیگنال **۰.۰۸٪** است:

```
سیگنال BUY  = +3.50 USD حرکت
هزینه       = -4.00 USD اسپرد
────────────────────────────
خالص        = -0.50 USD     ← هر معامله از قبل ضررده
```

یعنی مدل آموزش می‌دید حرکت‌هایی را شکار کند که **قبل از شروع** ضرر
می‌دادند. حق با تو بود که پرسیدی.

### رفع

`Mt5MarketDataProvider.live_quote(symbol)` اضافه شد که اسپرد را از تیک
زنده می‌خواند:

```python
tick = mt5.symbol_info_tick(symbol)
spread = tick.ask - tick.bid        # نه symbol_info.spread
```

چرا `ask - bid` و نه `symbol_info.spread`؟ چون دومی یک عدد صحیح در واحد
point و فقط یک snapshot است؛ اولی قیمتی است که **همین الان** در دسترس
است. عدد صحیح هم برای تشخیص کنارش برگردانده می‌شود.

خروجی:
```python
{"bid":4376.12, "ask":4376.47, "spread":0.35,
 "spread_pct":0.0000800, "spread_points":35, ...}
```

### رفتار در شکست

اگر ترمینال بسته باشد یا بازار تعطیل، **تیک نمی‌شکند**:

| حالت | نتیجه |
|---|---|
| بروکر جواب داد | همان عدد، `last_spread_source="broker"` |
| تیک وجود ندارد | fallback `0.35`، با ذکر علت |
| bid یا ask صفر | fallback (بازار بسته) |
| اسپرد ≤ ۰ | fallback |

نبود اسپرد یک مشکل داده است، نه دلیلی برای توقف منطق معاملاتی. ولی
`last_spread_source` همیشه ثبت می‌شود تا اجرا قابل حسابرسی باشد.

fallback جدید **۰.۳۵ دلار** است — اسپرد واقع‌بینانهٔ طلای خرد — نه ۴ دلار.

## ۳. راهنمای انتخاب آستانه بر اساس اسپرد واقعی تو

اسپردت را در MT5 ببین: Market Watch → راست‌کلیک روی XAUUSD →
Specification. بعد:

| اسپرد تو | آستانهٔ پیشنهادی | چرا |
|---|---|---|
| زیر ۰.۵ دلار | **۰.۰۸٪** (فعلی) | متعادل: ۳۰٪ خرید / ۲۹٪ فروش / ۴۱٪ نگه‌داشتن |
| ۰.۵ تا ۱.۵ | ۰.۱۵٪ | محافظه‌کارتر، ۶۵٪ HOLD |
| بالای ۲ | ۰.۲۵٪ | فقط ۸.۶٪ سیگنال می‌ماند |

توزیع واقعی روی دیتای ۵ دقیقهٔ خودت (۴۹٬۸۹۷ کندل) در گزارش قبلی
اندازه‌گیری شد.

## بدهی صریح

- **اسپرد فقط در حلقهٔ زنده استفاده می‌شود، نه در بک‌تست.**
  `run_backtest.py` هنوز `--spread 4.0` پیش‌فرض دارد. برای بک‌تست
  معنادار باید اسپرد میانگین واقعی را دستی بدهی.
- **آستانه در رکورد مدل ذخیره نمی‌شود.** دو مدل سیگنال با آستانه‌های
  متفاوت از روی فایلشان قابل تشخیص نیستند. باید به `ModelRecord` اضافه
  شود.
- `live_quote` روی ویندوز با متاتریدر واقعی **تست نشده** — در سندباکس با
  MT5 قلابی آزموده شد. اولین اجرای واقعی تو اولین آزمون واقعی‌اش است.
