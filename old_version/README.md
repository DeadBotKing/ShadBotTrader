# old_version

این فولدر نسخهٔ قبلی کامل همین پروژهٔ ShadBotTrader است.

در 2026-10-20 از ریشهٔ فعال جدا شد تا مسیر جاری فقط این چهار بخش را نگه دارد:

```text
MetaTrader data ingest
dataset build
feature build
range model
```

این فولدر `legacy/` نیست.

```text
legacy/       کد قدیمی خود مالک. دست نخورده. با این فولدر قاطی نشده.
old_version/  نسخهٔ قبلی همین ShadBotTrader، قبل از خلوت‌کردن.
```

ساختار داخلی همان مسیر قبلی است: `src/`, `scripts/`, `tests/`, `docs/`.
از ریشهٔ فعال import نمی‌شود. برای دیدن کد قدیمی همین‌جا را باز کن، نه `legacy/` را.
