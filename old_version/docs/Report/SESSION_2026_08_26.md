# گزارش کامل جلسه — 2026-08-26

## خلاصه اجرایی

در این جلسه سیستم ShadBotTrader از یک سیستم ناپایدار با trades=0 و
engine=legacy به یک سیستم dual engine کار کننده تبدیل شد.

---

## ۱. آنالیز بکتست اولیه (backtest_trades.csv)

### مشکلات کشف‌شده:
- **range_high/low_offset ثابت**: مدل range collapse شده بود
- **engine=legacy**: مدل‌ها لود نمیشدن
- **trades=0**: همه سیگنال‌ها توسط gate chain رد میشدن
- **R/R gate اشتباه**: mid=(high+low)/2 → R/R همیشه 1.0 → با threshold=1.5 همه رد

## ۲. تغییرات Signal Model

### معماری (فاز ۵۸):
| پارامتر | قبلی | جدید |
|---------|------|------|
| window_size | 150 | **300** (25 ساعت) |
| n_layers_per_block | 3→4 | **5** |
| n_blocks | 2 | 2 |
| RF | 57→121 | **249** (21h, 83% coverage) |
| default window | 100 | **300** |

### Training:
- **ReduceLROnPlateau**: اضافه شد (قبلاً فقط range داشت)
- **EarlyStopping**: اضافه شد
- **AdamW** (weight_decay=1e-5): بجای Adam
- label_smoothing: تست شد ولی SparseCategoricalCrossentropy ساپورت نمیکنه → حذف شد

---

## ۳. تغییرات Range Model

### seq2seq (فاز ۵۵-۵۶):
- **output shape**: [batch, 2] → [batch, window, 2]
- **gradient**: 150× قوی‌تر
- **collapse**: جلوگیری میکنه
- **horizon=1**: فقط کندل فردا (نه 5 کندل)
- **timeframe=1D**: یه روز کامل context

### Loss (فاز ۵۴):
- 3×Huber + 6×MAE + 1×MSE (ایده از legacy/TimeSeriesPrediction2.py)
- delta=0.005 (بجای 0.001)
- AdamW + ReduceLROnPlateau + EarlyStopping

## ۸. گام‌های بعدی

1. **آموزش signal** از صفر با تنظیمات جدید:
   ```
   --epochs 50 --window 300 --threshold 0.006 --learning-rate 0.0001
   ```

2. **آموزش range** از صفر:
   ```
   --epochs 50 --window 150 --range-timeframes 1D --learning-rate 0.001
   ```

3. **بکتست** با R/R=1.0 → بررسی trades > 0

4. **Session filter** فعال کن اگه trades کافی بود:
   - ساعت‌های 2,5,6,10,14,15,16,18 UTC

5. **آموزش هفتگی**: هر جمعه شب، هر دو مدل را resume کن
