## ۲. 🎯 ریشه — نه باگ، بلکه «تضاد هندسی ذاتی»

### زنجیرهٔ رویداد (با اعداد):

1. سیگنال فقط وقتی actionable می‌شود که قیمت **±0.6%** (~$24) حرکت کرده باشد
2. مدل رنج 1H حول closeِ آخرین کندلِ بسته‌شده باند می‌سازد:
   `predicted_low ≈ ref − 0.6%` · `predicted_high ≈ ref + 0.6%`
3. سیگنال SHORT یعنی قیمت ۰.۶٪ **بالا** رفته → entry نزدیک predicted_high
4. براکت SHORT: `SL = predicted_high + spread` → **فاصلهٔ SL از entry فقط ~spread ($2-4)**
5. گیت ۷ (فیکس باگ ۵۴، حالا درست کار می‌کند): `$2-4 < $10` → **HOLD → رد**
6. سناریوی قرینه برای LONG بعد از نزول ۰.۶٪ — همان نتیجه

**به زبان ساده:** سیگنال دقیقاً لحظه‌ای صادر می‌شود که قیمت به مرزِ باند رنج
رسیده — و SL دقیقاً روی همان مرز قرار می‌گیرد. پس SL همیشه چسبیده به
entry خواهد بود و هر min SL dist > $4 همه‌چیز را رد می‌کند.

### چرا با 1D این اتفاق نمی‌افتاد؟

باند 1D عرض ~1.1-1.3% داشت و **ref تا ۴۸ ساعت قدیمی** بود — گاهی entry
داخل باند (براکت سالم)، گاهی بیرون (وارونه/بازسازی). تنوع داشت.
باند 1H **باریک‌تر از خودِ آستانهٔ سیگنال** است → همیشه مرزی.

## ۴. 🛠️ سه راه‌حل واقعی

### راه ۱ — horizon بزرگ‌تر روی 1H (پیشنهاد اصلی، فاز ۸۰ آماده است)

`Range horizon = 24` روی 1H → عرض باند ~1.1-1.3% (هم‌ارز 1D) ولی
**هر ساعت رنج تازه**. مرزها دورتر از نقطهٔ سیگنال → SL فاصلهٔ واقعی
می‌گیرد → ترید باز می‌شود.

```bash
python scripts/run_dual_models.py --with-features --symbol XAUUSD \
  --model range --range-timeframes 1H --horizon 24 --epochs 30 \
  --folds 3 --window 150 --train-ratio 80.0 --learning-rate 0.0005 \
  --es-patience 12 --rlr-patience 5 --storage-root datasets
```

### راه ۲ — آستانهٔ سیگنال را به اندازهٔ باند 1H کم کن

`threshold = 0.3%` → سیگنال وسط باند صادر می‌شود → entry داخل باند →
SL فاصلهٔ طبیعی (~$10-20) دارد. ولی: تریدهای بیشتر و شاید کیفیت کمتر.

### راه ۳ — min SL dist موقتاً $5

با min=$5 بخشی از سیگنال‌ها عبور می‌کنند (SL فاصلهٔ $5-10 مجاز) —
اما نیمی از تریدها همچنان رد می‌شوند. راهِ نهایی نیست.
