۱ از کندل تا ماتریس

هر کندل یک‌روزهٔ طلا یک «سطر» می‌شود؛ اندیکاتورهای non-causal حذف؛ به هر سطر ۲ ستون برچسب هم می‌چسبد.

حالا مهم‌ترین قسمت — برچسب هر سطر از کجا می‌آید؟ از «فردای همان سطر»:

high_off[t] = (high[t+1] − close[t]) / close[t] low_off[t] = (low[t+1] − close[t]) / close[t]
ترجمه: «فردا نسبت به امروزِ بسته‌شده چند درصد بالاتر اوج می‌گیرد و چند درصد پایین‌تر کف می‌زند؟» دقیقاً همان چیزی که برای بستن براکت TP/SL فردا لازم است.

۲ یک نمونهٔ آموزشی — جفت (X , y)

پنجره‌ای از ۱۵۰ سطر که در سطر end تمام می‌شود. X ورودی است، y برچسب — و چون seq2seq است، هر سطرِ X برچسبِ فردای خودش را دارد (نه فقط سطر آخر).

چرا y پهن است (۱۵۰×۲) و نه فقط ۲ عدد؟ seq2seq = گرادیان ۱۵۰ برابر مترکم‌تر (فاز ۵۵) و مانع collapse. مدل خروجی را هم به همین شکل [150×2] می‌دهد؛ loss: ۴۰٪ کل سکانس + ۶۰٪ سطر آخر. موقع ترید فقط سطر آخرِ خروجی خوانده می‌شود = high/low فردا.

۳ سر خوردن پنجره — ۴٬۳۳۱ نمونه

پنجره یکی‌یکی به جلو می‌لغزد (stride=1)؛ از ۴٬۴۸۰ سطر، ۴۴۸۰ − ۱۵۰ + ۱ = ۴٬۳۳۱ نمونه ساخته می‌شود. هم‌پوشانی ۱۴۹ سطری بین همسایه‌ها طبیعیِ سری زمانی است.

۴ تقسیم آموزش/ولید — walk-forward پاک‌سازی‌شده (بدون شافل)
